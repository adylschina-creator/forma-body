# FORMA BODY — Frontend

Учебный проект: демонстрационный сайт программы домашних тренировок.
Текущая версия включает только секцию **Hero** (первый экран).

## Стек

- React 18
- TypeScript
- Vite
- Обычный современный CSS (без фреймворков)

## Как запустить

1. Установите [Node.js](https://nodejs.org/) версии 18 или новее (если ещё не установлен).
2. Откройте эту папку в VS Code.
3. Откройте встроенный терминал (`Ctrl+\`` или `Terminal → New Terminal`).
4. Установите зависимости:

   ```
   npm install
   ```

5. Запустите сайт в режиме разработки:

   ```
   npm run dev
   ```

6. В терминале появится ссылка вида `http://localhost:5173` — откройте её в браузере.

Сайт будет автоматически обновляться в браузере при любом изменении кода.

## Структура проекта

```
src/
├── components/
│   ├── ui/            # переиспользуемые мелкие детали (Button, Container)
│   └── sections/      # крупные смысловые блоки страницы (пока только Hero)
├── styles/            # глобальные стили и переменные (цвета, шрифты, отступы)
├── App.tsx            # собирает секции в страницу
└── main.tsx           # точка входа приложения
```
